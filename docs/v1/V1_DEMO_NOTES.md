# Notes de démonstration V1

## Préparation

1. Vérifier le compte, le garage actif et le branding.
2. Vérifier le slug public et les coordonnées de contact.
3. Préparer un véhicule complet et publié avec une couverture.
4. Vérifier les variables optionnelles du bridge et du fournisseur IA; ne pas les activer si elles ne sont pas configurées.

## Parcours conseillé

1. Se connecter et présenter les priorités du tableau de bord.
2. Ouvrir le stock, rechercher un véhicule puis consulter sa fiche.
3. Montrer les médias, la visite 360°, la visite intérieure et la préparation des annonces.
4. Présenter le workspace de publication.
5. Ouvrir `/g/[garageSlug]`, consulter le catalogue et envoyer une demande.
6. Revenir dans Demandes clients puis dans la Boîte commerciale.

Ne jamais présenter une intégration externe indisponible comme active. Utiliser les états explicites de l'interface pour expliquer les capacités optionnelles.
